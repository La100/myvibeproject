# Prompt do wygenerowania logo — Myvibe Project Manager

## Dla Midjourney / Ideogram / DALL-E 3

---

### Wersja pełna (pozioma, wordmark + ikona)

```
Minimalist professional logo for an architectural project management app called "myvibe".
The icon is a clean top-down floor plan enclosed in a rounded square.
Color palette: terracotta (#C06A3D) for the icon background, white for the floor plan lines,
sage green (#6D8B73) as accent.
The wordmark "myvibe" uses an elegant, thin-weight serif font (similar to Canela or Noe Display)
in near-black (#1A1A1A), followed by a small capslock tagline "PROJECT MANAGER" in sage green.
Overall aesthetic: warm, sophisticated, studio-clean. White or transparent background.
Vector style, no gradients, no shadows.
--style raw --ar 4:1 --v 6
```

## Wskazówki do iteracji

- Jeśli logo jest zbyt skomplikowane → dodaj: `ultra minimal, fewer details`
- Jeśli chcesz ciemnej wersji → dodaj: `dark background version, charcoal #1A1A1A background`
- Jeśli ikona powinna być okrągła → zmień: `rounded square` → `circle`
- Jeśli chcesz tylko ikonę bez tekstu → usuń opis wordmark
